# Day 001：LLM 基础——Token

## 🎯 今日目标
**Token到底是什么？**

## 📚 今日学习
简单理解：Token是大模型处理文本的基本单位。更深入的理解是：文字-->Token-->AI模型-->Token-->文字。

### 1、首先我们要先建立一个最重要的认知
很多初学者，就像我刚接触这个概念的时候一样，会认为:
> LLM大模型是直接阅读我们输入的文字

但是实际却不是这样的。举个例子：假设我输入：
> 你好，我是一名Java程序员

把这个问题提交给大模型处理的时候，大模型内部首先需要把这段文本转换成一组Token。我们可以粗略的理解成：
> 你好，我是一名Java程序员-->调用一个位于大模型内部的工具【Tokenizer】处理-->[Token1,Token2,Token3,...]-->LLM大模型处理

经过这个处理的流程我们可以知道：
> Token是文字进入到大模型之前的一种“数字化切片”

### 2、Token到底是什么？
我们现在先把token理解成是：
> 大模型处理文本时使用的基本单位

但是这里需要我们注意的是：
> Token不等于字符，Token也不等于单词，同时Token也不是汉字

它可能是：
+ 一个字符
+ 一个汉字
+ 一个单词
+ 一个单词的一部分
+ 标点符号
+ 空格
+ 某些常用的词组

具体怎么去做切分，是由具体大模型使用的分词器Tokenizer来决定的

#### 通过例子来理解
比如：
> I love java.

从我们人类看的话，可能认为是：
>I
> love
> Java
> .

总共是4个东西，但是大模型的分词器Tokenizer不一定能去这么做切分。它可能把文本切分为：
> I love Java
> .

所以的话怎么切分，由模型的分词器Tokenizer来具体决定。

### 3、为什么LLM大模型需要Token?
假设我们直接把文字交给计算机这句话：
> 你好，我喜欢Java

而计算机本质上是并不能直接把这些文字进行神经网络计算。神经网络需要的是：数字。所以中间需要经过一个过程：
> 我们人类的文字-->Tokenizer-->Token-->Token ID-->数字向量-->神经网络-->输出Token ID-->Token-->文字

因此我们可以把它理解成：
> 人类的世界-->“你好，我喜欢Java”-->Tokenizer-->[Token,Token,Token]-->Token ID-->[1323,3849,321...]-->神经网络

因此我们可以得到这样的答案：**Token是我们人类语言和神经网络之间的一座桥梁**。

### 4、Tokenizer是干什么的？
我们可以把Tokenizer理解成一个：文本切割和编码器。比如我们输入：
> I love Java

这个时候Tokenizer可能把这句话拆分成类似：
> ["I"," love"," Java"]

然后再给每个token一个编号：
> ["I"," love"," Java"]
>       =>
> [40,3021,5738]

这些数字我们叫它们：Token ID。但是在这里我们需要注意的是：具体的Token和Token ID 会根据不同的模型或Tokenizer分词器的不同而不同的。

### 5、Token不一定等于一个字
不管是中文还是英文，我们初学者在开始接触的时候，可能会认为一个token就是一个汉字或一个英文单词，但是实际上不一定是这样的
这一点需要我们能够辨别清楚就行。

### 6、为什么tokenizer不直接按照“单词或汉字”切呢？
举个例子：如果直接按照单词来切分：
> I love Programming

看起来很简单，但是问题来了，比如说：
> program
> 
> programming
> 
> programmer
> 
> programmers

如果我们认真观察会发现有很多词有相同的部分，如果每一个完整的单词都单独搞一个token，那么词表会非常的庞大。如果我们允许拆分：
> program
> 
> ming
 
这样操作的话，那么我们模型就可以利用已有的token组合出很多新词。 这个是一个非常重要的思想
